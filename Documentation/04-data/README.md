## Authority split

| Kind | Home |
| --- | --- |
| Code / domains | Pacific `RootRecord-Pacific-Solar-Server` |
| Knowledge, WOs, agent packs | Library |
| Generated bytes (Energy samples, logs, frames, WORKLOG) | **Database** (local) |
| Published weather (exception) | `RootRecord-Weather-Database` |

Logs are **Database**, not a Pacific code domain. See Pacific Domain Import Playbook.
