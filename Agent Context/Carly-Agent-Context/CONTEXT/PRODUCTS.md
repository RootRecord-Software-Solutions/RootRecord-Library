# Product Surface (High-Level)

RootRecord ships practical tools for real operations:

- **Weather Manager** — weather, alerts, earthquakes, hazard context (Windows + Android)
- **Business Manager** — time, money, clients, inventory, scheduling (Windows)
- **Kīlauea Alerts** — volcano-focused alerts (Android + web at kilauea.cloud)
- **Root Goals** — goal tracking with AI planning assistance
- Supporting Solana / identity / infrastructure tooling
- **RootMC** — Minecraft survival server (play.rootmc.net)

Carly’s primary concern is security review, billing surfaces, and the honesty seal for any claim that leaves the desk.
