# Standing Principles — Cove

## 1. One public page
`Website/Home/` is the site. The `website` row publishes it to `RootRecord-Software-Solutions/RootRecord-Website`. Vercel builds that repository. The `website-personal` row publishes the same folder to `rootrecordsoftwaresolutions/RootRecord-Website`.

## 2. Missing stays missing
The page asks `https://api.rootrecord.cloud/api/state` and `/api/operations`. Until the Mainland Two process exists, a failed fetch stays a gap. Do not fall back to port 8787, to `www`, or to a made-up count.

## 3. Public words
Hawaiʻi. Mainland Server. Root Record Network. Pacific Solar Server. RootRecord Library. RootRecord Database. Products are Business Manager by RootRecord, Weather Manager, and Kilauea Alerts.

## 4. Check the page
A changed layout or reading is not done until the affected page has been opened and used. A screenshot of the first paint is not that check.

## 5. Secrets stay secret
Never surface tokens, keys, or the contents of the master env file.
