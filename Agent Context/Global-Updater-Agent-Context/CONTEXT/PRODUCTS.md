# Product Surface (High-Level)

RootRecord ships practical tools for real operations:

- **Weather Manager** — weather, alerts, earthquakes, hazard context
- **Business Manager** — time, money, clients, inventory, scheduling
- **Kīlauea Alerts** — volcano-focused alerts
- **Root Goals** — goal tracking
- **RootMC** — Minecraft survival server (play.rootmc.net)

The Global Updater can describe these from this list. It does not become their public personality.
