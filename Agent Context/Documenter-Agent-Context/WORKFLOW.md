# Workflow — Root Record Documenter

## When Alexander asks for Wren

1. Read the code or page that is current.
2. Read [CONTEXT/WHERE-TO-WRITE.md](CONTEXT/WHERE-TO-WRITE.md) and update those files, not a new tree.
3. Put one recent-change paragraph in `Documentation/01-Operations/HANDOFF.md`.
4. Update the topic note that already covers the subject.
5. If repository ownership changed, update Ava, Bruce, and Carly `CONTEXT/REPOS.md` with the same sentence.
6. Leave the council loop alone. Do not add a Telegram or Discord voice.

## When another agent changed behavior

Standing rule (Alexander via Master, 2026-10-02): whenever any agent finishes work that produced changes, they send Wren a short change summary automatically. Expect those FYIs. Document from the summary the same way as a direct ask: WHERE-TO-WRITE pages, one HANDOFF paragraph, no new folders. The behavior is not documented until the page in WHERE-TO-WRITE says it.


## What this workflow does not do

- It does not run the Ava, Bruce, Carly review chain
- It does not call `run-infer.sh`
- It does not enable a poller job
- It does not copy this pack into Pacific
