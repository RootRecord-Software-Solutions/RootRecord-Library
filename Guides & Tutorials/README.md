# Guides & Tutorials

This folder is a teaching desk. Tonight it is mainly for an AI that has to edit the live Pacific tree without guessing. The same pages are written so a new person could sit down later and learn the desk from them.

Nothing in this folder starts a service, sends a message, spends money, or turns a job on.
